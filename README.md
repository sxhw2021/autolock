# 自动锁屏

设定 N 分钟内没有任何屏幕触摸操作就自动锁屏熄屏——即使前台是保持常亮的游戏。
适用于 ColorOS 16（Android 9 及以上均可），已 root 设备额外获得内核级触摸监测 + su 兜底锁屏。

## 下载安装

1. 将本仓库推送到 GitHub
2. 打开仓库 **Actions** 页 → 选择最新一次成功构建 → 底部 **Artifacts** 下载 `autolock-debug-apk`
3. 解压得到 `app-debug.apk`，传输到手机安装（需允许安装未知来源应用）
4. 推送 `v1.0.0` 这类 tag 会自动创建 Release 并附带 APK

## 开启步骤

1. 打开「自动锁屏」App
2. 点击「忽略电池优化」→ 弹窗中选择允许（防止系统冻结后台进程）
3. 点击「去开启」，在系统无障碍列表中找到「自动锁屏」并开启
4. 首次使用会弹出 root 授权请求（KernelSU/Magisk），请允许——这用于内核级触摸监测，绕过游戏模式对无障碍事件的过滤
5. 回到 App，状态卡片变绿即生效
6. 输入超时分钟数（1–720），点保存

## 保活指引

1. 确保已点击「忽略电池优化」并允许
2. 设置 → 电池 → 更多设置 → 找到「自动锁屏」→ 允许后台高耗电
3. 最近任务卡片下拉 → 锁定「自动锁屏」
4. 若无障碍被系统关闭，回到 App 重新开启
5. 确保已授权 root（内核级触摸监测需要）

## 真机验收清单

- [ ] 开启无障碍后状态卡片变绿
- [ ] 通知栏显示「自动锁屏运行中」
- [ ] 设 1 分钟，静置桌面 1 分钟后自动熄屏
- [ ] 游戏内静置同样触发
- [ ] 触摸屏幕后倒计时重置（59 秒时触摸不会在 1 秒后熄屏）
- [ ] 关闭总开关后不再触发
- [ ] 熄屏后再亮屏不会被立即锁定

## 技术原理

**问题**：游戏通过 WakeLock 保持常亮，系统自动锁屏失效；ColorOS 冻结后台进程，
无障碍事件被游戏模式过滤，导致"空闲不锁、一碰就锁"的反转行为。

**解决方案（三层防御）**：
1. **前台服务保活**：KeepAliveService 持有低优先级通知，防止 ColorOS 冻结进程
2. **多信号触摸检测**：
   - 无障碍服务监听 `TYPE_TOUCH_INTERACTION_START/END` + `TYPE_WINDOW_STATE_CHANGED`
   - **root 触摸监控**：`su -c getevent -ql` 直接读取内核输入事件流，完全绕过无障碍限制
3. **双重校验**：锁屏前检查 `PowerManager.isInteractive`，避免熄屏时误触发

每 5 秒轮询一次：无触摸时长 ≥ 设定值 → 执行锁屏（`GLOBAL_ACTION_LOCK_SCREEN` → su 兜底）。
