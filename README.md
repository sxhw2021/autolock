# 自动锁屏（LSPosed 模块）

在设定时间内未操作屏幕就自动锁屏，不耗电、不影响游戏。

基于 LSPosed 模块直接 hook 系统 `PowerManagerService.userActivity()`，
精准感知每一次用户操作，无需前台服务、无障碍权限，纯系统级实现。

## 安装步骤

1. 从 Actions 下载 APK 并安装
2. 打开 **LSPosed** → 模块 → 自动锁屏 → **启用**
3. 作用域选择 **「系统框架」**（android）
4. **重启手机**生效
5. 打开「自动锁屏」App 设置时长并启用

## 工作原理

- Hook 系统 `PowerManagerService.userActivity()` —— 每次用户触摸屏幕、按电源键等操作都会调用此方法
- 每次调用重置倒计时
- 倒计时到期时调用 `goToSleep()` 锁屏熄屏
- 根目录设备额外提供 `su -c input keyevent 26` 兜底

## 优势

| 对比项 | 无障碍服务方案 | 本模块（LSPosed） |
|--------|--------------|------------------|
| 前台服务 | 需要（耗电） | 不需要 |
| 无障碍权限 | 需要 | 不需要 |
| 游戏模式干扰 | 可能被过滤 | 直接 hook 系统，不受影响 |
| 进程冻结风险 | 需保活引导 | 无（hook 在系统进程内） |
| 省电 | 一般 | 极佳 |
